# Template Source

This project started from a free, MIT-licensed admin dashboard template as a
base, then was heavily trimmed and rebranded into the RAG dashboard.

Original repository (cloned to bootstrap the project):

- URL: https://github.com/TailAdmin/free-react-tailwind-admin-dashboard
- License: MIT, see `LICENSE.md` below for the original copyright notice.

The `LICENSE.md` in this repo retains the original MIT attribution required by
the template license. All template-specific branding, demo content and unused
pages/components have been removed.
